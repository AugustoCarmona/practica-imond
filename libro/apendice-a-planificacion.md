# Apéndice A. Planificación de 16 semanas

| Semana | Contenidos | Entregable o hito |
|---|---|---|
| 1 | Introducción a la materia, objetivos, EcoBottle, consola: navegación y rutas | Árbol de carpetas y registro de comandos |
| 2 | Git, GitHub, fork, clone, commits, ramas y trabajo colaborativo | Fork con primer commit y README inicial |
| 3 | Negocios digitales, estrategia, organizaciones data-driven, dato/información/conocimiento | Glosario y preguntas de negocio |
| 4 | Fuentes, tipos, calidad y diccionarios de datos; exploración de CSV | Inventario de las 13 fuentes |
| 5 | Bases de datos, motores y modelo relacional; PK, FK y cardinalidades | DER comentado |
| 6 | SQL básico: SELECT, WHERE, ORDER BY, GROUP BY y agregaciones | Consultas exploratorias |
| 7 | JOIN, NULL, cardinalidades, SQL y normalización | Práctica de consultas y explicación de errores |
| 8 | OLTP, ACID, operaciones de EcoBottle y repaso integrador | **Hito:** evaluación parcial de conceptos y SQL |
| 9 | OLAP, data warehouse, data lake y arquitecturas analíticas | Diagrama de arquitectura |
| 10 | ETL, ELT, extracción, carga, validaciones y ciclo de vida | Diseño de pipeline y controles |
| 11 | Kimball, grano y dimensiones; claves naturales y subrogadas | `sql/01_dimensiones.sql` y diseño estrella |
| 12 | Tablas de hechos y claves foráneas; carga y conciliación | `sql/02_hechos.sql` y pruebas |
| 13 | KPIs de ventas, ticket, actividad, NPS, provincias y productos | `sql/03_consultas.sql` con seis métricas documentadas |
| 14 | Marketing mix, segmentación, plan de marketing, storytelling y visualización | Borrador del tablero |
| 15 | Investigación de usuarios, accesibilidad, sesgos, privacidad, controles y revisión cruzada | Tablero mejorado, pruebas y README |
| 16 | Reproducibilidad, presentación de hallazgos, defensa técnica y entrega del fork con modelo y dashboard | **Hito:** trabajo práctico final |

Las semanas 1–8 priorizan fundamentos; las 9–16 integran arquitectura, ingeniería, analítica, marketing y presentación.
