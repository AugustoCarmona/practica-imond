# Apéndice C. Banco de ejercicios integradores

- **A.** Una empresa muestra más ventas por producto que ventas totales. Diagnosticar una multiplicación por `JOIN`.
- **B.** El KPI de «usuarios activos» suma sesiones anónimas y clientes identificados. Explicar por qué esas unidades no son equivalentes.
- **C.** El NPS mejoró mientras la tasa de respuesta cayó. Proponer hipótesis y controles de sesgo.
- **D.** Dos provincias muestran resultados distintos según dirección de envío o facturación. Elegir la regla correcta para la pregunta concreta.
- **E.** Los resultados cambian entre ejecuciones del mismo script. Investigar semillas, fuentes, orden de carga y dependencias.
- **F.** Un tablero muestra una mejora en ventas y atribuye el efecto a campañas. Explicar la diferencia entre asociación y causalidad.
- **G.** Un informe expone correos de clientes. Proponer mínimo privilegio, minimización y alternativas agregadas.
- **H.** Una transformación ejecutada dos veces duplica datos. Definir idempotencia y cómo recuperarla.
- **I.** Una tienda crea un pago sin confirmar el pedido. Vincular el error con las propiedades ACID.
- **J.** Un gerente solicita análisis mensual de ventas durante cinco años. Justificar un diseño analítico frente a consultar directamente una aplicación transaccional.
