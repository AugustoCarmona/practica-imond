# Apéndice B. Secuencia de evaluación formativa

- **Primer control (semana 4):** comprender consola, Git y el valor de los datos.
- **Segundo control (semana 8):** SQL, PK/FK, OLTP, ACID y normalización.
- **Tercer control (semana 12):** arquitectura, ETL/ELT, grano, dimensiones y hechos.
- **Defensa final (semana 16):** explicar SQL, justificar definiciones de KPIs, demostrar ejecución y comunicar una decisión empresarial.

Para cada control, el estudiante debe responder al menos tres preguntas: ¿qué construí?, ¿qué decisión de diseño tomé y por qué?, ¿cómo sé que el resultado es confiable?
