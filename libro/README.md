La teoría de cada capítulo se aplica sobre los datos y el proyecto integrador de la [práctica EcoBottle AR](../README.md).

## Cómo leerlo

Cada capítulo tiene la misma estructura: una definición académica, una explicación para quien recién empieza, la aplicación al caso EcoBottle y ejercicios con su evidencia de aprendizaje. Conviene leer los capítulos en orden: cada uno usa lo que se vio en el anterior.
